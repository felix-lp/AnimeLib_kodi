# AnimeLib для Kodi

Видео-аддон `plugin.video.animelib` для Kodi 19+ (Matrix, Nexus, Omega): каталог, поиск и просмотр аниме с [AnimeLib](https://anilib.me).

## Возможности

- Разделы: «Последние обновления», «Популярное», «По рейтингу», «Новое на сайте».
- Каталог по жанрам и типам (TV, фильм, OVA, ONA…), постраничная навигация.
- Поиск с историей запросов.
- Описание, постер, фон и жанры тайтла. Описания берутся с Shikimori (GraphQL, пачкой до 50 тайтлов):
  у AnimeLib они скопированы оттуда же, но без имён персонажей.
- Выбор озвучки или субтитров. Выбор запоминается для каждого тайтла; сменить его можно через контекстное меню эпизода: «Выбрать озвучку».
- Выбор максимального качества (по умолчанию 1080p; «Максимальное» включает 2160p, где оно есть).
- Пропуск опенинга, если на сайте есть разметка (настройка выключена по умолчанию).
- Плееры: **Kodik** (через него идёт почти всё видео на сайте) и собственный плеер **AnimeLib** с внешними субтитрами.

## Установка (с автообновлением)

1. В Kodi включите *Настройки → Система → Дополнения → Неизвестные источники*.
2. Скачайте `repository.animelib-1.0.1.zip`:
   <https://raw.githubusercontent.com/felix-lp/AnimeLib_kodi/refs/heads/gh-pages/repository.animelib/repository.animelib-1.0.1.zip>
3. *Дополнения → Установить из ZIP-файла* → выберите скачанный файл.
4. *Дополнения → Установить из репозитория → AnimeLib Repository → Видеодополнения → AnimeLib*.

Дальше Kodi сам подхватывает новые версии (или вручную: *Дополнения → Мои дополнения → AnimeLib → Обновить*).
Репозиторий собирается GitHub Actions при каждом push в ветку по умолчанию и публикуется в ветку `gh-pages`.

Чтобы Kodi мог скачивать файлы, репозиторий на GitHub должен быть публичным.

Локальная сборка: `python3 build.py` (zip-файлы в `dist/`) или `python3 build.py --repo DIR` (готовый Kodi-репозиторий).

## Аккаунт

*Настройки аддона → Аккаунт → Войти* (или пункт «Войти в аккаунт AnimeLib» в главном меню).
После входа:
- в главном меню появляются «Мои списки» (Смотрю, Запланировано, Просмотрено и т.д.);
- в контекстном меню тайтлов — «Добавить в список» / «Удалить из списка»;
- становится доступен собственный плеер AnimeLib (1080p, иногда 2160p) — без входа API отдаёт только Kodik (до 720p);
- эпизод, досмотренный до 85%, отмечается на сайте так же, как в браузере, а у тайтла из списков
  закладка переходит на этот эпизод; в списке эпизодов просмотренные помечены, следующий подсвечен «►».
Вход идёт через auth.lib.social так же, как на сайте (OAuth + PKCE, капча ALTCHA решается автоматически).
Токены, логин и пароль хранятся локально в `userdata/addon_data/plugin.video.animelib/account.json`;
пароль нужен для повторного входа, если токен истечёт.

## Медиатека Kodi

В контекстном меню тайтла — «Добавить в медиатеку Kodi», в контекстном меню списка в «Моих списках» —
«Добавить весь список в медиатеку Kodi». Аддон пишет в папку медиатеки (по умолчанию
`userdata/addon_data/plugin.video.animelib/library/`) по папке на тайтл: `tvshow.nfo`, `poster.jpg`, `fanart.jpg`
и `SxxEyy.strm` + `.nfo` на каждый эпизод. Новые эпизоды дописываются автоматически (по умолчанию раз в 12 часов,
настраивается в разделе «Медиатека»).

Папку нужно один раз подключить: *Видео → Файлы → Добавить видео…*, в поле пути (не через «Обзор» — он не
показывает скрытую AppData) ввести `special://profile/addon_data/plugin.video.animelib/library/`, тип содержимого
«Сериалы», источник информации «Local information only». Либо указать в настройках аддона любую видимую папку.

## Цвета списков

После входа тайтлы, которые есть в ваших списках, подсвечиваются цветом списка с сайта
(Смотрю — оранжевый, Запланировано — синий, Брошено — красный, Просмотрено — зелёный, остальные — розовый).

## Как устроено

AnimeLib берёт данные из открытого JSON API (`https://api.cdnlibs.org/api`, заголовок `Site-Id: 5`):

| Запрос | Что возвращает |
|---|---|
| `GET /anime?q=&page=&sort_by=&sort_type=desc&genres[]=&types[]=` | каталог и поиск (60 тайтлов на страницу) |
| `GET /anime/{slug_url}?fields[]=summary&fields[]=genres&...` | карточку тайтла |
| `GET /episodes?anime_id={slug_url}` | список эпизодов |
| `GET /episodes/{id}` | эпизод со списком плееров (`players`): команда, тип перевода, ссылка |
| `GET /constants?fields[]=genres&fields[]=types&fields[]=videoServers` | справочники |
| `POST /auth/oauth/token` | токены (authorization_code / refresh_token) |
| `GET /auth/me` | текущий пользователь |
| `GET /bookmarks/folder/{user_id}` | списки пользователя |
| `GET /bookmarks?user_id=&status={folder}&page=` | тайтлы в списке |
| `GET /anime/{slug_url}/bookmark`, `POST /bookmarks`, `DELETE /bookmarks/{id}` | закладка тайтла |

У плеера Kodik ссылка ведёт на страницу `kodikplayer.com/seria/...`. Аддон берёт из неё подписанные параметры, отправляет POST-запрос на эндпоинт плеера (сейчас `/ftor`) и расшифровывает ссылки на HLS-потоки. Это base64 со сдвигом букв. Эндпоинт и величину сдвига аддон каждый раз ищет в JS плеера, так что небольшие изменения на стороне Kodik он переживёт.

Если API переедет на другой домен, его адрес можно поменять в настройках аддона (раздел «Сеть»).

## Структура

```
repository.animelib/           # Kodi-репозиторий (указывает на ветку gh-pages)
plugin.video.animelib/
├── addon.xml                  # версию поднимать при каждом изменении
├── main.py                    # точка входа
└── resources/
    ├── settings.xml
    ├── language/              # ru_ru, en_gb
    └── lib/
        ├── animelib.py        # клиент API AnimeLib
        ├── auth.py            # вход в аккаунт (OAuth + ALTCHA)
        ├── kodik.py           # получение прямых ссылок из Kodik
        ├── library.py         # экспорт в медиатеку Kodi (.strm + .nfo)
        ├── service.py         # фоновый сервис: отметка просмотра, пропуск опенинга, обновление медиатеки
        ├── parallel.py        # параллельные HTTP-запросы без потоков (потоки роняют Python в Kodi)
        ├── players.py         # выбор плеера и качества
        ├── shikimori.py       # описания и жанры с Shikimori
        ├── plugin.py          # меню и маршрутизация Kodi
        └── http.py            # HTTP на urllib (без зависимостей)
```
